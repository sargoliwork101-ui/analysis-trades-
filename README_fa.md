# نبض بازار 📈

ویجت صفحه‌ی اصلی اندروید برای **قیمت لحظه‌ای بازار** — بورس تهران، کریپتو، طلا و ارز، و بازارهای جهانی — با ظاهر دلخواه خودت. کاتلین؛ تنظیمات با Jetpack Compose و ویجت با RemoteViews.

**[📥 دانلود آخرین نسخه](https://github.com/sargoliwork101-ui/analysis-trades-/releases/latest)** — انگلیسی: [README.md](README.md)

## ✨ قابلیت‌ها

### ویجت (سه اندازه: کوچک، متوسط، بزرگ)
- **تنظیمات مستقل هر ویجت** — هر ویجت منابع، نمادها، مقادیر و تم خودش را دارد؛ با زدن روی ویجت تنظیمات همان باز می‌شود.
- **۵ تم** — تیره، روشن، شیشه‌ای، شفق قطبی، نئون — با جداکننده‌ی رنگی ردیف‌ها.
- **اندازه‌ی پویا** — فونت و محتوا با اندازه‌ی واقعی ویجت + ضریب فونت کاربر (×۰٫۷۵ تا ×۱٫۵).
- **واحد زیر عدد قیمت** — تومان/ریال/$ برای همه‌ی منابع و همه‌ی اندازه‌های ویجت به یک شکل نشان داده می‌شود؛ حتی واحدِ **هر نماد جدا** (انس طلا دلار است، سکه تومان). تغییر، حجم و نمودار هم در ردیف است.
- **نمودار مینیاتوری برای همه‌ی نمادها و همه‌ی اندازه‌های ویجت** — همه یا هیچ: یا برای همه روشن است یا برای هیچ‌کدام. تاریخچه‌ی قیمت روی خود گوشی ذخیره می‌شود، پس حتی نمادهای بورس تهران هم نمودار می‌گیرند؛ تعداد نقاط نمایش (۶ تا ۶۰) را کاربر تعیین می‌کند.
- **مقاوم در برابر خطا و بی‌اینترنتی** — بدون اینترنت یا با خاموش‌کردن به‌روزرسانی خودکار، ویجت خالی نمی‌شود: آخرین قیمت‌ها روی صفحه می‌ماند، **LED چشمک‌زن** هر ردیف قرمز/سبز می‌شود (سبز=تازه، قرمز=قدیمی، خاکستری=بدون داده) و نوار پایین می‌گوید الان در چه وضعیتی است. ساعت آخرین به‌روزرسانی هم در هدر است.
- **وضعیت همه‌ی بازارهای ویجت** — کنار ساعت، باز/بسته بودن هر بازاری که در همین ویجت فعال است: «بورس: بسته 🔴 • کریپتو: باز ۲۴/۷ 🟢 • جهانی: باز 🟢 • طلا و ارز: …»؛ قابل خاموش کردن.
- **مرتب‌سازی هوشمند** — دستی، بیشترین تغییر روز یا الفبا.
- **کنترل تعداد نمایش** — چند نماد (۱ تا ۶) در هر ویجت دیده شود.

### هشدارها 🔔
- شرط‌ها: بالاتر/پایین‌تر از قیمت، رشد/افت درصدی و **جهش حجم نسبت به نمونه‌ی قبلی**؛ زمان‌بندی هر هشدار و فاصله‌ی ضداسپم.
- **تاریخچه‌ی هشدارها** — تا ۲۰۰ اعلان تحویل‌شده با زمان و مقدار رخداد روی خود گوشی نگه داشته می‌شود و قابل پاک‌کردن/بکاپ است.
- **خواب موقت** — با یک دکمه نوتیف‌ها ۱۵/۳۰/۶۰ دقیقه می‌خوابند (میتینگ/خواب).
- نوتیف‌ها فقط **یک ویبره‌ی تکیِ لطیف** (۷۰ میلی‌ثانیه) می‌دهند.

### پامپ‌های کریپتو 🔥 (قابل مخفی‌کردن)
- **آموزش پامپ** — پامپ چیست، «پامپ گروهی / Pump & Dump» چطور کار می‌کند و چه نشانه‌هایی دارد.
- **اسکن زنده‌ی بازار** — کوین‌های برتر CoinGecko خوانده می‌شوند و با یک امتیاز ترکیبی (رشد ۲۴ ساعته + ۲× رشد ۱ ساعته + نسبت حجم به ارزش بازار) کوین‌های در حال پامپ جدا می‌شوند؛ دامنه‌ی اسکن (۵۰/۱۰۰/۲۵۰ کوین برتر) و آستانه‌ی رشد (۳ تا ۲۵٪) قابل تنظیم است.
- **پیشنهاد احتیاطی همراه با دلیل** برای هر نتیجه؛ بر پایه‌ی سطح ریسک، شتاب ۱ ساعته، رشد ۲۴ ساعته و نسبت حجم به ارزش بازار. خروجی‌ها فقط «زیر نظر بگیر / عجله نکن / قیمت را تعقیب نکن» هستند و عمداً سیگنال خرید ندارند.
- **آلارم اختیاری پامپ** با فاصله‌ی ضداسپم قابل تنظیم؛ اسکن‌های پس‌زمینه حداقل ۱۵ دقیقه فاصله دارند، هر نتیجه فقط یک‌بار بررسی می‌شود و اعلان نیز پیشنهاد و دلیل روشن را نشان می‌دهد.
- **نظر دوم هوش مصنوعیِ اختیاری** — کاربر آدرس هر API سازگار با OpenAI، نام مدل و کلید خودش را وارد می‌کند؛ AI پیشنهاد پایه را با دلیل و میزان اطمینان بررسی می‌کند و، اگر سرویس پشتیبانی کند، خبرهای مرتبط را با لینک می‌آورد. اجرا فقط با دکمه‌ی هر کوین است و AI هرگز جای تحلیل احتیاطی پایه را نمی‌گیرد.
- **برچسب ریسک** هر کوین (کم‌ریسک‌تر / پرنوسان / پرخطر) + دکمه‌ی «ویجت» برای افزودن همان کوین به ویجت و زیر نظر گرفتن رفتارش.
- **قواعد احتیاط** در همان صفحه و یادآوری «این سیگنال خرید نیست».

### به‌روزرسانی و مصرف نت ⏱
- سرویس زنده با فاصله‌ی دلخواه (۵ تا ۱۲۰ ثانیه) + پشتیبان WorkManager هر ۱۵ دقیقه.
- **بازه‌ی ساعتی به‌روزرسانی** — «از ساعت تا ساعت» تعیین کن تا فقط همان ساعت‌ها از اینترنت تازه شود و بسته‌ی نت زود تمام نشود؛ رفرش دستی همیشه کار می‌کند. بازه‌ی شب‌گذر هم پشتیبانی می‌شود.

### رابط تنظیمات
- رابط فارسی در همه‌ی گوشی‌ها به‌صورت اجباری **راست‌به‌چپ (RTL)** نمایش داده می‌شود.
- طراحی تمیزِ بخش‌بخش (منو ← هر بخش صفحه‌ی خودش)، پیش‌نمایش زنده‌ی ویجت، انتخاب تم با سواچ رنگی، و پنجره‌های یکدست.
- **واچ‌لیست‌های نام‌دار** — ترکیب نمادهای یک ویجت را با نام ذخیره و روی ویجت دیگر اعمال کن.
- **بکاپ و بازگردانی** — خروجی/بازیابی تنظیمات، واچ‌لیست‌ها و تاریخچه‌ی هشدارها به‌صورت JSON.
- **آپدیت درون‌برنامه‌ای** — آخرین ریلیز گیت‌هاب چک می‌شود، **اثر انگشت SHA-256 فایل** نشان داده می‌شود و نسخه‌ی جدید **روی همان نصب** نصب می‌شود؛ چیزی پاک نمی‌شود.

### منابع داده
- **سلامت منابع** — آخرین موفقیت/خطا، زمان پاسخ، میزبان فعال و استفاده از fallback داخل برنامه دیده می‌شود؛ endpoint خراب موقتاً به انتهای صف می‌رود و دوباره آزمایش می‌شود.
- **تشخیص قیمت غیرعادی** — پرش توضیح‌داده‌نشده‌ی ۴۰٪ یا بیشتر یک نوبت قرنطینه می‌شود؛ آخرین قیمت سالم می‌ماند و نمونه‌ی دوم می‌تواند قیمت تازه را تأیید کند.
- داخلی: **بورس تهران (TSETMC)** + شاخص کل، **CoinGecko** (کریپتو)، **TGJU** (دلار آزاد، طلا و سکه، و **انس جهانی طلا/نقره**) و **TradingView** (طلا، نقره، نفت، شاخص دلار و کریپتو).
- **منبع دلخواه** — هر API جیسون (مسیر نقطه‌ای، قالب گروهی، ضریب و واحد) یا صفحه‌ی HTML (سلکتور CSS)؛ حتی واحد مخصوص یک نماد با `@` (مثل `ons:انس طلا@$`). جستجوی نماد بورس با نام یا لینک صفحه‌ی TSETMC.
- 📡 برای انتقال لایه‌ی دریافت منابع به اپ/پلتفرم دیگر: [SOURCES_SPEC_fa.md](SOURCES_SPEC_fa.md) — مشخصات کامل مدل داده، مسیریابی JSON، APIهای TSETMC و استراتژی کش.
- 🏗 برای توسعه‌ی بعدی: [ARCHITECTURE_fa.md](ARCHITECTURE_fa.md) — نقشه‌ی ماژول‌ها و «قوانین طلایی».
- 🔍 نتیجه‌ی ممیزی امنیت و مهندسی: [AUDIT_fa.md](AUDIT_fa.md).

## 🥇 قیمت طلای جهانی — چطور ببینم؟

دو راه داخلی دارید؛ هر دو «انس جهانی طلا» را به **دلار** می‌دهند (نه تومان):

**راه ۱ — TGJU (بدون فیلترشکن، مناسب اینترنت ایران)**
1. تنظیمات ویجت ← **منابع داده** ← «طلا و ارز — TGJU» را روشن کنید.
2. **نمادها** ← «جستجو یا افزودن نماد» ← منبع TGJU ← روی **«انس طلا (جهانی)»** بزنید
   (برای نقره: «انس نقره (جهانی)»).
3. تمام؛ روی ویجت با واحد `$` دیده می‌شود.

**راه ۲ — TradingView (قیمت اسکنر رسمی، ۲۴/۵)**
1. **منابع داده** ← منبع «بازارهای جهانی — TradingView» را روشن کنید.
2. **نمادها** ← **«طلا — انس جهانی»** (نماد `OANDA:XAUUSD`) را انتخاب کنید.
3. اگر شبکه‌تان TradingView را فیلتر کرده باشد، این منبع جواب نمی‌دهد؛ همان راه ۱ را
   استفاده کنید (یا منبع «انس طلا» را با کد دلخواه `TVC:GOLD` امتحان کنید).

> نکته‌ی فنی: قیمت طلا در بازار داخلی (گرم ۱۸ عیار، مثقال، سکه) هم در همان منبع TGJU
> موجود است؛ می‌توانید هم‌زمان «انس جهانی» و «سکه امامی» را در یک ویجت بگذارید —
> واحد هر کدام خودکار درست نمایش داده می‌شود.

## 🔁 نسخه‌ها
- برای **هر تغییر**، حتی تغییر کوچک، رفع اشکال یا مستندات، `versionCode` و `versionName` افزایش می‌یابند؛ هیچ مجموعه‌تغییری بدون نسخه‌ی تازه ثبت نمی‌شود. نسخه‌های انتشار با GitHub Release (تگ `v*`) ارائه می‌شوند تا آپدیت درون‌برنامه‌ای آن‌ها را بگیرد.
- CI با هر پوش APK می‌سازد: [Actions](https://github.com/sargoliwork101-ui/analysis-trades-/actions)
  - فایل نصبی همیشه در بخش **Artifacts** همان اجرا با نام `PulseMarket-Android-APK` بالا می‌آید (داخلش `PulseMarket-vX.Y.apk`).
  - از نسخه‌ی ۱٫۲۱، CI یک **APK انتشار بهینه** می‌سازد، تست‌های واحد و lint انتشار را اجرا می‌کند و امضا را می‌سنجد؛ از ۱٫۲۳ خوانده‌نشدن اثر انگشت امضا شکست قطعی است. گیت حجم APK فقط یک نردبان ایمنی در برابر رشد ناخواسته‌ی وابستگی/دارایی است — نه الزام محصولی؛ از ۱٫۵۶ روی ۵ MiB (به‌جای ۲ MiB سخت‌گیرانه‌ی قبلی) تنظیم شده و اگر هیچ سقفی نمی‌خواهید، همان گام CI را حذف کنید.
- **همه‌ی نسخه‌ها با یک کلید ثابت امضا می‌شوند** (`app/ci-debug.keystore`) تا نسخه‌ی جدید *روی همان نصب قبلی* نصب شود و آپدیت درون‌برنامه‌ای کار کند. اگر کلید هر بیلد عوض شود، اندروید نصب را رد می‌کند (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`). این کلیدِ «دیباگ/سایدلود» است، نه کلید گوگل‌پلی.
- ⚠️ نسخه‌های ۱٫۰ تا ۱٫۳ با کلیدِ تصادفیِ سرورهای CI امضا شده بودند؛ برای نصب **۱٫۴** روی آن‌ها یک‌بار حذف و نصب مجدد لازم است. از ۱٫۴ به بعد این کار لازم نیست.

**تاریخچه‌ی نسخه‌ها**
- **۱٫۶۰** — **آپدیت درون‌برنامه‌ای با یک دکمه**: بخش «درباره ← به‌روزرسانی برنامه» دیگر فقط مرورگر را باز نمی‌کند. وقتی بررسی، نسخه‌ی جدیدی پیدا کند، با یک دکمه‌ی «⬇ دانلود و نصب»، خودِ برنامه APK را دانلود می‌کند (با نوار پیشرفت زنده)، اثر انگشت SHA-256 آن را با ریلیز گیت‌هاب تطبیق می‌دهد و نصب‌کننده‌ی سیستم را مستقیم روی همین نصب باز می‌کند — بدون دانلود دستی و بدون گشتن در فایل‌منیجر. در اندروید ۸ به بعد، اگر اجازه‌ی «نصب برنامه‌های ناشناس» نباشد آن را تشخیص می‌دهد و دکمه‌ی «اجازه و نصب» کاربر را به صفحه‌ی درست می‌برد و سپس نصب می‌کند. فقط آدرسِ ریلیز رسمیِ همین مخزن و نامِ `PulseMarket-v*.apk` قبول می‌شود و اندروید هم امضای کلید ثابت را بررسی می‌کند، پس آپدیت امن می‌ماند. یک `FileProvider`، مجوز `REQUEST_INSTALL_PACKAGES`، تابع دودوییِ `Http.download()` با سقف حجم و پیشرفت، و کمکیِ `AppInstaller` اضافه شد.
- **۱٫۵۹** — دو مورد بهینه‌سازی از فهرست ممیزی، بدون تغییر در رفتارِ قابل‌مشاهده. (۱) **کش دیسکِ مشترک OkHttp** (۵ مگابایت): کلاینت واحدِ HTTP برنامه حالا یک کش دیسک دارد که در `Application.onCreate` آماده می‌شود. فقط پاسخ‌های GET ای را نگه می‌دارد که خودِ سرور با `Cache-Control`/`ETag` قابل‌کش اعلام کرده، پس داده‌ی قیمتِ زنده که `no-cache` است هرگز کهنه سرو نمی‌شود؛ سود اصلی درخواست‌های شرطی (`304 Not Modified`) است که مصرف داده/پهنای‌باند تکراری را کم می‌کند، در کنار کشِ دو دقیقه‌ایِ خودِ اسکنر. (۲) **بازه‌ی وفق‌پذیرِ کارگر پس‌زمینه**: کارگرِ پشتیبانِ دوره‌ای دیگر همیشه هر ۱۵ دقیقه بیدار نمی‌شود. اگر ویجت زنده‌ای باشد روی کمینه‌ی ۱۵ دقیقه می‌ماند (پشتیبانِ تنگ برای وقتی سرویس زنده کشته شود)؛ و اگر فقط آلارم پامپ فعال باشد، بازه با cooldownِ آلارم هم‌تراز می‌شود (چون اسکنِ زودتر از cooldown اعلان تازه‌ای نمی‌سازد) و باتری/داده صرفه می‌شود. محدود به کف ۱۵ دقیقه‌ای اندروید و سقف منطقی ۶ ساعت.
- **۱٫۵۸** — همه‌ی state و منطقِ صفحه‌ی پامپ به یک `PumpsViewModel` (`AndroidViewModel`) منتقل شد. پیش‌تر نتیجه‌ی هر اسکن، نظر هوش مصنوعی، معامله‌ی آزمایشی و کشِ «معامله در نوبیتکس» داخل خود composable با `remember` نگه داشته می‌شد؛ پس با ترک و بازگشت به بخش پامپ (یا چرخش/تغییر پیکربندی صفحه) همه از دست می‌رفت و یک اسکن شبکه‌ای تازه به‌اجبار انجام می‌شد. حالا state در ViewModelِ scope‌شده به Activity می‌ماند، پس بازگشت فوری است و دوباره به شبکه نمی‌زند، و منطق شبکه/دیسک به‌طور تمیز از UI جدا شد. composable حالا state را از راه `val`های آینه‌ای می‌خواند و برای هر تغییر متد `vm.…` را صدا می‌زند، پس بدنه‌ی بزرگ UI بدون کوچک‌ترین تغییر ماند — و این ریسک بازآرایی را کم می‌کند. هیچ تغییری در رفتارِ قابل‌مشاهده برای کاربر نیست.
- **۱٫۵۷** — رابط تنظیمات/پامپ حالا به‌طور خودکار از حالت **روشن یا تیره‌ی گوشی** پیروی می‌کند. یک پالتِ رنگیِ روشن در کنار تیره‌ی موجود اضافه شد و با `isSystemInDarkTheme()` انتخاب می‌شود. این کار امن بود چون بررسی نشان داد همه‌ی متن/پس‌زمینه‌ی برنامه از تم می‌خوانند (`MaterialTheme.colorScheme.*`)؛ تنها رنگ‌های ثابت، رنگ‌های نشانه‌ای (سبز سود/قرمز ضرر/کهربایی هشدار که روی هر دو پس‌زمینه خوانا هستند) و رنگ‌های *پیش‌نمایشِ* تم ویجت‌اند که عمداً ثابت می‌مانند چون ظاهر خودِ ویجت را نشان می‌دهند، نه ظاهر برنامه.
- **۱٫۵۶** — بازطراحی کیف معامله‌ی آزمایشی. حالا یک «کارت معامله»ی زیبا و مشترک، هم در تب «کیف» بخش پامپ و هم در تب «معامله‌های من» استفاده می‌شود: هر کارت با نام کوین و یک برچسب رنگیِ سود/زیان شروع می‌شود، بعد یک شبکه‌ی دو‌ستونه‌ی مرتب از قیمت خرید، قیمت فعلی/فروش، مبلغ سرمایه و ارزش فعلی، و مهم‌تر از همه — چیزی که قبلاً نبود — **زمان خرید و زمان فروش** (به‌همراه دلیل بسته‌شدن)، و نیز حد سود/حد ضرر/سربه‌سر و کارمزد را روشن نشان می‌دهد. یک کارت خلاصه‌ی امروزی هم کل کیف را (نتیجه‌ی کل، محقق‌شده/باز، نرخ برد، کارمزد) در چیپ‌های فشرده جمع می‌کند. کارت متنیِ شلوغِ قبلی و کدِ تکراریِ کارت معامله حذف شد. ضمناً گیت حجم APK در CI از ۲ MiB سخت‌گیرانه به ۵ MiB (نردبان ایمنی) شل شد — این یک بررسیِ خودخواسته‌ی CI بود، نه الزام محصول.
- **۱٫۵۵** — بهبود کارایی و کیفیت بخش پامپ بدون تغییر رفتار: کلاس‌های داده‌ی کوین/معامله با `@Immutable` علامت خوردند و فهرست نتایج با شناسه‌ی کوین `key` شد تا Compose از recompositionهای بی‌مورد هنگام اسکرول صرف‌نظر کند؛ نقشه‌ی قیمت‌های زنده یک‌بار ساخته و در مسیر کیف/فروش دوباره استفاده می‌شود؛ و هنگام اسکن یک نوار پیشرفت نازک زیر تب‌ها دیده می‌شود. تست `FormatTest` برای فرمت قیمت/درصد/حجم/ارقام فارسی/زمان اضافه شد. (چند پیشنهاد از قبل پیاده شده بود — دسته‌بندی خطای هوش مصنوعی برای ۴۰۱/۴۰۳/۴۲۹/تایم‌اوت، تست‌های اسکنر، گیت سقف ۲ مگابایتی APK در CI و کش دو دقیقه‌ای خودِ اسکنر — پس دست‌نخورده ماند؛ مهاجرت کامل به ViewModel و تم روشن عمداً به تعویق افتاد تا زیر سقف سخت‌گیرانه‌ی حجم APK بمانیم و رگرسیون ظاهریِ تأییدنشده رخ ندهد.)
- **۱٫۵۴** — بازچینش رابط بخش «پامپ کریپتو» و ظاهر امروزی‌تر در کل برنامه. صفحه‌ی شلوغ و طولانی پامپ حالا به چهار **تب** تقسیم شده است: «پامپ‌ها» (نتیجه‌ی اسکن + راهنما + دکمه‌ی اسکن تازه)، «اسکن» (تنظیمات اسکن زنده)، «هوش‌مصنوعی» (راه‌اندازی نظر دومِ اختیاری) و «کیف» (کیف معامله‌ی آزمایشی)؛ نوار تب گِرد و امروزی است و تب انتخاب‌شده به‌خاطر سپرده می‌شود. در کل برنامه هم گوشه‌ی کارت‌ها، دکمه‌ها، چیپ‌ها و دیالوگ‌ها نرم‌تر و مدرن‌تر شد. هیچ تغییری در رفتار، منطق یا اعداد نیست — فقط چیدمان و ظاهر.
- **۱٫۵۳** — ساده‌سازی کد خرید پله‌ای بدون هیچ تغییر در ظاهر، قابلیت یا منطق: فیلدهای `entryHigh/entryLow` (که همیشه برابر قیمت پله‌ی اول/آخر بودند) از حالت ذخیره‌شده به «محاسبه‌شونده» تبدیل شدند تا داده‌ی تکراری ذخیره نشود؛ کدِ مرده (`pendingStepCount`) و یک متغیر محلیِ اضافی حذف شد و ساختِ پله‌ها خواناتر شد. خروجی، اعداد و رابط کاربری دقیقاً مثل ۱٫۵۲ است.
- **۱٫۵۲** — قابلیت‌های نوبیتکسی در شبیه‌ساز: «خرید پله‌ای» با «محدوده‌ی ورود» و «حد ضرر». حالا می‌توانی مبلغ را در چند پله (۲ تا ۱۰) از قیمت فعلی تا یک کف درصدی (محدوده‌ی ورود) پخش کنی؛ پله‌ی اول همان لحظه پر می‌شود و پله‌های پایین‌تر با افت قیمت در هر اسکن خودکار پر می‌شوند. «میانگین ورود» به‌صورت میانگین وزنیِ هزینه بازمحاسبه می‌شود و حد سود/حد ضرر روی همین میانگین اعمال می‌شود. کارت معامله در تب «معامله‌های من» و صفحه‌ی جزئیات کوین، وضعیت هر پله (پرشده/در انتظار)، محدوده‌ی ورود و سرمایه‌ی به‌کاررفته/کل را نشان می‌دهد.
- **۱٫۵۰** — ممیزی کیفیت کد بدون تغییر ظاهر یا قابلیت‌ها: فرمت ساعت انتخاب‌گر زمان در تنظیمات به `Locale.US` پین شد تا روی گوشی‌های با زبان عربی/فارسی، ارقام همانند بقیه‌ی برنامه یکدست بماند (پیش‌تر به زبان گوشی وابسته بود)؛ و در تب «معامله‌های من»، دکمه‌ی «به‌روزرسانی قیمت‌ها» با `try/finally` محافظت شد تا حتی با خطای غیرمنتظره هم دوباره فعال شود و روی حالت «در حال گرفتن…» قفل نماند.
- **۱٫۴۹** — تب مستقل «معامله‌های من»: هر کوینی که خرید آزمایشی برایش ثبت کرده‌ای با جزئیات کامل (قیمت خرید، قیمت فعلی، کارمزد، سر به سر، حد سود/ضرر، زمان‌ها و دلیل بسته‌شدن) آنجا می‌ماند؛ قیمت‌ها مستقل از اسکن پامپ و مستقیم برای همان کوین‌ها گرفته می‌شوند، حد سود/ضرر با هر به‌روزرسانی بررسی می‌شود و خلاصه‌ی سود محقق‌شده، سود باز، نرخ برد و کارمزد کل نمایش داده می‌شود.
- **۱٫۴۸** — کارت هر کوین کاملاً از بقیه جدا شد (کارت مستقل با سایه، حاشیه و نوار رنگی بر اساس دسته‌ی امتیاز، قیمت و امتیاز در هدر)؛ و سرعت پاسخ AI: خاموش‌کردن فاز «تفکر» روی مدل‌های ۲٫۵ گوگل، کوتاه‌کردن prompt (به‌جای کل سری قیمت فقط ۸ نقطه)، کاهش سقف توکن خروجی به ۲۰۴۸ و سقف زمان کوتاه‌تر برای مسیرهای پشتیبان تا کاربر سه بار پشت هم منتظر نماند.
- **۱٫۴۷** — رفع خطای نوع (Int/Float) در محاسبه‌ی گام جابه‌جایی نمودار شمعی؛ زوم و درگ نمودار درست کامپایل و کار می‌کند.
- **۱٫۴۶** — کارمزد خرید و فروش در شبیه‌ساز (پیش‌فرض ۰٫۲٪ هر سمت، قابل تغییر) با نمایش سود خالص، قیمت سر به سر و مجموع کارمزد؛ نمودار اصلی شمعی شد با انتخاب بازه (۱ روز ساعتی، ۷ روز، ۳۰ روز، ۳ ماه)، زوم و جابه‌جایی دو انگشتی و ابر ایچیموکو روی همان کندل‌ها؛ دکمه‌ی نمودار به TradingView تغییر کرد (لینک CoinGecko به‌عنوان گزینه‌ی فرعی ماند)؛ سقف زمان پاسخ AI به ۱۸۰ ثانیه رسید؛ و امتیاز پامپ دسته‌بندی و معنا پیدا کرد (کم‌جان زیر ۱۵، متوسط ۱۵–۳۵، قوی ۳۵–۷۰، بیش‌ازحد داغ بالای ۷۰).
- **۱٫۴۵** — رفع خطای اعشار شناور در شبیه‌ساز معامله: قیمت دقیقاً روی سطح حد سود/حد ضرر هم باعث بسته‌شدن معامله می‌شود (قبلاً ۱۱۰٫۰۰۰۰۰۰۰۰۰۰۰۰۰۱ مانع فعال‌شدن حد سود می‌شد).
- **۱٫۴۴** — حد سود/حد ضرر معامله‌های آزمایشی هنگام باز شدن صفحه هم با آخرین قیمت کش‌شده بررسی می‌شود (نه فقط پس از اسکن تازه).
- **۱٫۴۳** — شبیه‌ساز معامله (paper trading): ثبت «خرید آزمایشی» با مبلغ، حد سود و حد ضرر درصدی، فروش دستی، بسته‌شدن خودکار با رسیدن قیمت به حد سود/ضرر در اسکن‌های بعدی، کارت «کیف آزمایشی» با سود محقق‌شده، سود باز، نرخ برد و تاریخچه؛ به‌علاوه نمایش «این کوین در نوبیتکس معامله می‌شود یا نه» با کش ۲۴ ساعته.
- **۱٫۴۲** — پرسش از AI کاملاً فنی شد: تحلیل عددی تکنیکال، سطح ورود/حد ضرر/هدف/افق زمانی/باطل‌کننده، معرفی پشتوانه و تیم و توکنومیکس پروژه، محرک‌های خبری و «نظر کارشناسی خلاصه»؛ ابر ایچیموکو (تنکان، کیجون و ابر) روی نمودار ۷ روزه اضافه شد و وضعیت آن به مدل هم فرستاده می‌شود؛ گزینه‌ی آماده‌ی LLMsRelay (Claude) با هدرهای Anthropic افزوده شد.
- **۱٫۴۱** — هر دو مسیر Gemini کنار هم نگه داشته شدند: درخواست اول از مسیر بومی می‌رود و اگر پاسخ بی‌متن (مثل MALFORMED_FUNCTION_CALL) بدهد، همان درخواست خودکار از مسیر سازگار با OpenAI گوگل تکرار می‌شود؛ گزینه‌ی آماده‌ی «Gemini (سازگار OpenAI)» برگشت، تست اتصال می‌گوید از کدام مسیر پاسخ گرفته و خطای کلید/سهمیه/مسدودی بی‌خود روی مسیر دوم تکرار نمی‌شود.
- **۱٫۴۰** — رفع خطای `MALFORMED_FUNCTION_CALL` مدل‌های Gemini: پاسخ با خروجی ساختاریافته (`responseMimeType` و `responseSchema`) درخواست می‌شود، در صورت بروز این خطا یک بار خودکار در حالت متن ساده تکرار می‌شود و پیام فارسی روشن هم نمایش داده می‌شود.
- **۱٫۳۹** — رفع «پاسخ متن قابل‌خواندن نداشت» روی مدل‌های thinking گوگل: بخش‌های thought نادیده گرفته می‌شوند، سقف توکن خروجی به ۴۰۹۶ (و تست به ۵۱۲) رسید و به‌جای پیام مبهم، دلیل واقعی (MAX_TOKENS، فیلتر ایمنی، نبود candidate، refusal مسیر OpenAI) نمایش داده می‌شود.
- **۱٫۳۸** — پشتیبانی از مسیر بومی Gemini (`/v1beta/models/{model}:generateContent` با هدر `X-goog-api-key`) تا کلیدهای Google AI Studio مستقیم کار کنند؛ preset گوگل به `gemini-flash-latest` تغییر کرد و تست اتصال هم از همین مسیر استفاده می‌کند.
- **۱٫۳۷** — پیام خطای سرویس AI حالا از بدنه‌ی JSON بیرون کشیده و به فارسی ترجمه می‌شود: محدودیت جغرافیایی Gemini، کلید نامعتبر/منقضی، نام مدل اشتباه، سهمیه و نبود دسترسی؛ سقف متن پاسخ سرویس در خطاها از ۶۰ به ۲۴۰ کاراکتر رسید و راهنمای preset گوگل درباره‌ی مسدودی ایران به‌روز شد.
- **۱٫۳۶** — ممیزی کامل: رفع دریافت‌نشدن BOOT_COMPLETED (رسیور بوت باید exported باشد، وگرنه ویجت‌ها بعد از ری‌استارت تازه نمی‌شدند)، محافظت از crash سرویس زنده در برابر ForegroundServiceStartNotAllowedException، ایمن‌سازی NotificationManager تهی در موتور هشدار و سرویس زنده، ساخت یک‌باره‌ی کانال اعلان و سبک‌سازی کش پامپ (ذخیره‌ی نمودار فقط برای ۶۰ کوین نخست).
- **۱٫۳۵** — دکمه‌ی «تست اتصال به سرویس AI» با پیام نتیجه‌ی دقیق، پیام‌های خطای گویا (۴۰۱/۴۰۳/۴۰۴/۴۲۹، DNS، TLS، تایم‌اوت و مسدودی) همراه با متن کوتاه پاسخ سرویس، افزایش سقف زمان درخواست AI به ۹۰ ثانیه و ارسال هدرهای اختصاصی Anthropic در کنار Bearer.
- **۱٫۳۴** — کوچک‌سازی (subset) فونت وزیرمتن به کاراکترهای واقعاً استفاده‌شده‌ی فارسی/لاتین؛ حجم APK حدود ۱۷۰ کیلوبایت کم شد و دوباره زیر سقف ۲ مگابایتی قرار گرفت.
- **۱٫۳۳** — صفحه‌ی جزئیات هر کوین پامپ با کلیک روی آن: نمودار ۷ روزه، تغییرات ۱س/۲۴س/۷ر/۳۰ر، حجم و ارزش بازار و گردش حجم، سقف/کف ۲۴ ساعته و جای قیمت در آن، ATH و فاصله تا آن، عرضه در گردش/کل، «مرحله‌ی حرکت»، هشدار بازار کم‌عمق، تفکیک امتیاز پامپ، مقایسه با اسکن قبلی، نظر AI با خبرهای لینک‌دار و دکمه‌های افزودن به ویجت و باز کردن CoinGecko.
- **۱٫۳۲** — افزودن «تنظیمات پیش‌فرض سرویس» (Gemini، Claude، OpenAI و OpenRouter) به بخش پامپ، کلید روشن/خاموش جست‌وجوی وب سرویس، پشتیبانی از مسیر سازگار `/v1beta/openai` گوگل، رفع گم‌شدن کلید API هنگام مهاجرت از نسخه‌ی ۱٫۱۸ و ایمن‌سازی `NotificationManager` تهی در هشدار پامپ.
- **۱٫۳۱** — جایگزینی call siteهای API-24 مربوط به `Iterable.forEach` با حلقه‌های ترتیبی هم‌ارز `for` تا سازگاری Android 6 به بسته‌ی کامل stream وابسته نباشد؛ خروجی UI و ترتیب اجرا تغییر نکرد.
- **۱٫۳۰** — حفظ semantics کامل CSS selector دلخواه با پیمایش ترتیبی DOM بدون Stream؛ build سازگار Android 6 اکنون به‌جای پیاده‌سازی‌های بلااستفاده‌ی stream فقط desugaring حداقلی function/Optional را بسته‌بندی می‌کند.
- **۱٫۲۹** — حذف نگه‌داری غیرضروری metadata مربوط به annotation/inner-class از قواعد R8 و بسته‌بندی فقط منابع فارسی به‌همراه fallback انگلیسی؛ RTL، ظاهر و رفتار اجرایی تغییر نکرد.
- **۱٫۲۸** — جایگزینی کنترل بیش‌ازحد محافظه‌کارانه‌ی رشته‌های خام DEX (که descriptorهای بی‌خطر backport را هم می‌گرفت) با تست رگرسیون مسیر واقعی parse HTML و CSS selector؛ lint انتشار، minSdk 23 و desugaring استاندارد همچنان اجباری‌اند.
- **۱٫۲۷** — عبور مستقیم متن HTML از parser خود jsoup؛ منبع دلخواه با CSS selector حفظ شده و برنامه ورودی‌های بلااستفاده‌ی file/Path را فراخوانی نمی‌کند.
- **۱٫۲۶** — حفظ jsoup امن روی Android 6 همراه با جایگزینی NIO filesystem بلااستفاده با desugaring استاندارد stream/function؛ آزمایش محافظه‌کارانه‌ی descriptorهای DEX در ۱٫۲۸ دقیق‌تر شد.

## 🛠 ساخت

```bash
./gradlew assembleRelease  # APK بهینه در app/build/outputs/apk/release/
./gradlew test lintRelease # تست‌های واحد + lint نسخه‌ی انتشار
```
کاتلین ۲٫۴٫۲۰ · AGP 8.9 · compile/target API 36 · minSdk 23 (اندروید ۶ به بالا)

## 🔐 نکته
- تنظیمات فقط در حافظه‌ی خود گوشی (DataStore/SharedPreferences) است؛ حساب کاربری یا کلید مخفی در کد نیست.
- منابع دلخواهِ http فقط با انتخاب خود کاربر و با هشدار خوانده می‌شوند.
- خواندن شبکه فقط از ماژول `Http` انجام می‌شود: فقط HTTP(S)، با سقف حجم پاسخ، redirect محدود و حذف هدر حساس روی HTTP یا تغییر میزبان.
- API Key تحلیل هوش مصنوعی با AES-GCM و کلید Android Keystore ذخیره می‌شود و هرگز روی HTTP ارسال نمی‌شود.
- پیام‌های داخلی ویجت با یک توکن خصوصی امضا می‌شوند تا برنامه‌های دیگر نتوانند رفرش/حالت زنده را از بیرون کنترل کنند.
- پیشنهاد باقی‌مانده‌ی ممیزی درباره‌ی کلید امضا در [AUDIT_fa.md](AUDIT_fa.md) توضیح داده شده است.

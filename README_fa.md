# نبض بازار — ویجت لحظه‌ای سهام/کریپتو برای اندروید

ویجتی روی صفحه‌ی اصلی گوشی که به‌صورت خودکار (حالت زنده) از سایت‌های انتخابی تو قیمت می‌خواند و نشان می‌دهد:
قیمت + درصد تغییر + حجم معاملات + نمودار مینیاتوری، با پنج تم (تیره، روشن، شیشه‌ای، شفق قطبی، نئون) و پشتیبانی از اعداد فارسی.
هر ویجت تنظیمات مستقل خودش را دارد: نمادها، مقادیر نمایشی، تم، اندازه‌ی فونت و …

---

## ۱. چه چیزی ساخته شده؟

```
pulse-widget/
├── app/src/main/java/com/pulse/market/
│   ├── data/
│   │   ├── Model.kt          مدل‌ها: منبع، نماد، قیمت، تنظیمات
│   │   ├── Alert.kt          مدل قانون هشدار (شرط + بازه‌ی زمانی + روزها + کول‌داون)
│   │   ├── AlertEngine.kt    موتور بررسی هشدارها و فرستادن نوتیف
│   │   ├── SourceCatalog.kt  لیست منابع آماده (کریپتو، TSETMC، طلا و ارز، یاهو، اسکرپ وب)
│   │   ├── Fetcher.kt        موتور خواندن از سایت‌ها (JSON و HTML) با OkHttp + Jsoup
│   │   ├── JsonPath.kt       مسیرخوان کوتاه: result[0].price
│   │   ├── Num.kt            تبدیل «۱۲٬۳۴۵ تومان» به عدد
│   │   ├── ConfigStore.kt    ذخیره‌ی تنظیمات (DataStore)
│   │   └── QuoteRepo.kt      گرفتن موازی + کش آخرین قیمت‌ها
│   ├── widget/
│   │   ├── StockWidgetProvider.kt  گیرنده‌ی ویجت (رفرش، روشن/خاموش حالت زنده)
│   │   └── WidgetRenderer.kt       ساخت ظاهر ویجت
│   ├── service/
│   │   ├── LiveUpdateService.kt    سرویس پیش‌زمینه = قلب «به‌روزرسانی لحظه‌ای»
│   │   ├── LiveUpdateWorker.kt     پشتیبان هر ۱۵ دقیقه (اگر سرویس کشته شد)
│   │   └── BootReceiver.kt         راه‌اندازی خودکار بعد از ری‌استارت گوشی
│   └── ui/
│       ├── MainActivity.kt   صفحه‌ی تنظیمات، انتخاب منبع/نماد و لیست هشدارها
│       ├── AddSourceDialog.kt  پنجره‌ی «منبع دلخواه»
│       ├── AddAlertDialog.kt   پنجره‌ی ساخت/ویرایش هشدار (شرط + زمان‌بندی + روزها)
│       ├── Theme.kt          تم تیره + فونت وزیرمتن
│       ├── Format.kt         قالب‌بندی قیمت/درصد/ساعت + اعداد فارسی
│       └── Sparkline.kt      نمودار مینیاتوری
├── app/src/main/res/font/    فونت‌های وزیرمتن (Regular/Medium/Bold)
├── app/src/main/res/layout/widget_stock.xml   ساختار ویجت
└── preview/widget-preview.html                پیش‌نمایش طراحی (همین حالا بازش کن)
```

**حالت زنده چطور کار می‌کند؟** یک سرویس پیش‌زمینه (با اعلان کم‌اهمیت) هر N ثانیه که در تنظیمات می‌گذاری، قیمت‌ها را موازی می‌گیرد و ویجت را رندر می‌کند. روی اندروید خود سیستم اجازه‌ی بازه‌ی کمتر از ۵ ثانیه را نمی‌دهد (به‌خاطر باتری)، ولی ۱۰ تا ۳۰ ثانیه کاملاً روان و «لحظه‌ای» حس می‌شود. اگر سرویس را بکشد، یک Worker هر ۱۵ دقیقه قیمت را تازه می‌کند تا عدد قدیمی روی ویجت نماند.

## ۲. ساخت و نصب

### راه ۱ — بیلد خودکار در سرورهای ابری گیت‌هاب (ساده‌ترین، بدون نیاز به نصب هیچ برنامه‌ای)
این پروژه به صورت پیش‌فرض شامل ورک‌فلو آماده‌ی **GitHub Actions** است. کافیست پروژه را به یک ریپازیتوری در گیت‌هاب خود Push کنید:
1. در [github.com](https://github.com) یک ریپازیتوری جدید بسازید.
2. با دستورات زیر پروژه را بفرستید:
   ```bash
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git branch -M main
   git push -u origin main
   ```
3. در گیت‌هاب به تب **Actions** بروید؛ سرور به صورت خودکار ظرف ۲ دقیقه پروژه را کامپایل کرده و فایل نصبی **`PulseMarket-Android-APK`** را در بخش **Artifacts** برای دانلود قرار می‌دهد!
4. *(راهنمای کامل و گام‌به‌گام در فایل `GITHUB_APK_GUIDE_fa.md` قرار دارد).*

### راه ۲ — با Android Studio
1. پوشه‌ی `pulse-widget` را در Android Studio باز کن: `File → Open`.
2. صبر کن تا Sync تمام شود.
3. گوشی را با کابل وصل کن و **Run ▶** را بزن یا از منوی `Build → Build APK(s)` فایل نصبی را دریافت کن.

### راه ۳ — خط فرمان
```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### اضافه کردن ویجت به صفحه‌ی اصلی
روی فضای خالی هوم‌اسکرین نگه دار → **Widgets** → «نبض بازار» را بکش روی صفحه →
صفحه‌ی تنظیمات خودش باز می‌شود → منبع و نمادها را انتخاب کن → **ذخیره و به‌روزرسانی**.

## ۳. تنظیمات مهم

| گزینه | توضیح |
|---|---|
| **منبع داده** | از لیست منابع آماده یکی را بزن، یا «منبع دلخواه» بساز |
| **نمادها** | حداکثر ۶ نماد برای هر ویجت — با حذف (🗑) و جابه‌جایی (فلش‌ها) (می‌توانی چند ویجت با منابع مختلف بگذاری) |
| **مقادیر نمایشی** | حجم معاملات/حجم ۲۴ ساعت، درصد تغییر، کد نماد، نمودار، ساعت و نوار وضعیت — هر کدام جداگانه روشن/خاموش |
| **به‌روزرسانی خودکار (حالت زنده)** | روشن باشد، سرویس هر N ثانیه قیمت می‌گیرد |
| **فاصله‌ی به‌روزرسانی** | ۵ تا ۱۲۰ ثانیه (پیشنهاد: کریپتو ۱۰–۳۰ / بورس تهران ۶۰) |
| **تم** | تیره / روشن / شیشه‌ای (Glassmorphism) / شفق قطبی (Aurora) / نئون (Cyber) — برای هر ویجت جداگانه |
| **اندازه‌ی فونت** | ضریب ۰٫۷۵ تا ۱٫۵ دلخواه کاربر + بزرگ‌شدن خودکار با اندازه‌ی ویجت |
| **جداکننده‌ی رنگی ردیف‌ها** | هر نماد با رنگ زمینه‌ی متناوب از بقیه جدا می‌شود |
| **اعداد فارسی** | ۶۴٬۲۱۰٫۴۵ → ۶۴,۲۱۰.۴۵ فارسی |
| **اعداد فشرده** | ۶۴٫۲ هزار / 12.4M به‌جای عدد کامل |
| **نمودار مینیاتوری** | فقط منابعی که سری قیمت می‌دهند (مثل Yahoo) نمودار دارند |

**روی خود ویجت:** `⟳` = رفرش فوری • زدن روی نام منبع = روشن/خاموش کردن حالت زنده • زدن روی بدنه = باز شدن تنظیمات.

## ۳.۵. هشدار قیمت با زمان‌بندی (نوتیف)

در صفحه‌ی تنظیمات، بخش **«۴. هشدار قیمت (نوتیف)»**:

برای هر نماد یک قانون بساز و تعیین کن:

| بخش | گزینه‌ها |
|---|---|
| **شرط** | قیمت بالاتر از X • قیمت پایین‌تر از X • رشد بیش از ٪X • افت بیش از ٪X |
| **بازه‌ی زمانی** | مثلاً ۰۹:۰۰ تا ۱۲:۳۰ با انتخاب ساعت (بازه‌های شب‌گذر مثل ۲۲:۰۰ تا ۰۶:۰۰ هم کار می‌کند) |
| **روزهای هفته** | شنبه تا جمعه، هر ترکیبی |
| **میان‌بر** | «ساعات بورس تهران» یا «شبانه‌روزی (کریپتو)» با یک ضربه |
| **فاصله‌ی نوتیف‌ها** | هر بار / ۵ دقیقه / ۱۵ دقیقه / ۳۰ دقیقه / ۱ ساعت / ۳ ساعت |
| **فقط لحظه‌ی عبور** | روشن باشد، فقط وقتی قیمت از حد رد می‌شود نوتیف می‌آید (نه در هر رفرش تا وقتی بالای حد است) |

- قانونی که می‌سازی **بلافاصله ذخیره** می‌شود (نیازی به دکمه‌ی ذخیره‌ی پایین صفحه ندارد).
- بررسی هشدارها همراه با هر بار تازه شدن قیمت‌ها انجام می‌شود → با **حالت زنده** هر ۱۵–۳۰ ثانیه چک می‌شود.
- روی هر کارت قانون، کلید روشن/خاموش و سطل حذف هست؛ برای ویرایش، روی خود کارت بزن.
- اگر روی کارت هشدار بزنی و شرایط را عوض کنی، همان قانون به‌روز می‌شود (نه یکی جدید).
- در نوار بالای ویجت اگر 🔔 ببینی یعنی هشدار فعال داری و در خط پایین ویجت تعدادشان نوشته می‌شود.
- دکمه‌ی **«تست نوتیف»** در تنظیمات، یک نوتیف آزمایشی فوری می‌فرستد تا مطمئن شوی اجازه‌ی اعلان داده‌ای.
- اگر نوتیف نیامد: تنظیمات گوشی → اپ‌ها → نبض بازار → اعلان‌ها → کانال **«هشدار قیمت»** باید فعال باشد (کانال جدا از اعلان سرویس زنده است).

### مثال‌های آماده
| می‌خواهم… | شرط | زمان‌بندی |
|---|---|---|
| صف خرید فولاد را از دست ندهم | قیمت ≥ ۶۴۲۰ ریال | شنبه–چهارشنبه، ۰۹:۰۰–۱۲:۳۰ |
| ریزش بیت‌کوین را بگیرم | افت ≥ ۵٪ | هر روز، شبانه‌روز، هر ۱ ساعت |
| کف خرید دلار | قیمت ≤ ۹۰٬۰۰۰ تومان | هر روز، ۱۰:۰۰–۱۸:۰۰ |

> نکته: هشدار «رشد/افت ٪» از درصد تغییر همان لحظه‌ی منبع استفاده می‌کند (برای کریپتو = ۲۴ ساعته، برای سهام آمریکا = نسبت به قیمت پایانی قبل).

### فونت
فونت اپ **وزیرمتن** است (نسخه‌ی ۳۳.۰۰۳، سه وزن Regular/Medium/Bold) و هم در ویجت (`res/font/vazirmatn_*.ttf`) و هم در صفحه‌های تنظیمات (Compose) استفاده می‌شود.

### برای اینکه حالت زنده کشته نشود
- در اعلان‌ها، نوتیفیکیشن «نبض بازار» را حذف نکن (همان چیزی است که سرویس را زنده نگه می‌دارد).
- گوشی‌های شیائومی/هواوی/سامسونگ: در تنظیمات باتری، برای «نبض بازار» **Autostart** و **No battery restrictions** را روشن کن.
- اگر ویجت خطا نشان داد، در تنظیمات دکمه‌ی **تست داده** را بزن؛ متن دقیق خطا (مثلاً «سلکتور پیدا نشد») را نشان می‌دهد.

### ۳.۶ نمادهای بورس تهران (جستجوی آنلاین یا وارد کردن لینک TSETMC)

اگر منبع «بورس تهران — TSETMC» را انتخاب کنید، دکمه‌ی اختصاصی **«🔍 جستجو در بورس تهران یا افزودن با لینک TSETMC»** فعال می‌شود:
- **جستجو با نام نماد:** می‌توانید هر نمادی از بازار بورس، فرابورس، صندوق‌های اهرمی و طلا (مثل `اهرم`، `عیار`، `کهربا`، `طلا`، `شتران`، `خودرو`، `خساپا`، `دی`...) را تایپ و جستجو کنید.
- **وارد کردن مستقیم لینک TSETMC:** کافیست وارد سایت `tsetmc.com` شوید، صفحه‌ی سهم را باز کرده و لینک آن را کپی کنید (مثلاً `https://tsetmc.com/instInfo/46348633615832441` یا ISIN یا فرمت‌های قدیمی). دکمه‌ی چسباندن (Paste) را در برنامه بزنید تا هوشمندانه مشخصات سهم و قیمت پایانی واکشی شود و به لیست اضافه گردد.
- **محاسبه هوشمند سود/زیان:** درصد تغییر روزانه سهام بر اساس قیمت دیروز محاسبه شده و با رنگ سبز (مثبت) یا قرمز (منفی) روی ویجت نمایش می‌یابد.

## ۴. ساخت «منبع دلخواه» (سایت‌هایی که خودت می‌گویی)

دو حالت دارد:

**الف) سایت API جیسون می‌دهد** → آدرس را با `{symbol}` بگذار و مسیر قیمت را بنویس:
```
آدرس:      https://api.example.com/price?symbol={symbol}
مسیر قیمت: data.last.price          ← نقطه = پایین رفتن در JSON، [] = ایندکس آرایه
مسیر تغییر: data.last.change
معنی تغییر: درصد / مقدار / قیمت دیروز
```
مثال واقعی (یاهو) که در اپ هم هست:
```
آدرس:       https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?interval=5m&range=1d
مسیر قیمت:  chart.result[0].meta.regularMarketPrice
مسیر تغییر: chart.result[0].meta.chartPreviousClose   ← معنی تغییر: «قیمت دیروز»
مسیر نمودار: chart.result[0].indicators.quote[0].close
```

**ب) صفحه‌ی HTML معمولی است (اسکرپ)** → سلکتور CSS بده:
```
آدرس:      https://www.example.com/stock/{symbol}
سلکتور CSS: #price .value  یا  span.last-price
(اختیاری) خواندن از ویژگی: content
```

> نکته‌ی مهم: سایت‌ها هر چند وقت یک‌بار HTML خودشان را عوض می‌کنند. اگر منبع HTML از کار افتاد، فقط سلکتور را
> با Inspect مرورگر روی همان صفحه به‌روز کن (در پنجره‌ی منبع دلخواه قابل ویرایش است).

**ضریب (scale):** اگر سایت قیمت را ریال می‌دهد و تومان می‌خواهی `0.1`؛ اگر سنت می‌دهد و دلار می‌خواهی `0.01`.

### منابع آماده‌ی داخل اپ
| منبع | منبع داده | نکته |
|---|---|---|
| کریپتو (۸ ارز) | CoinGecko | بدون کلید، سریع و پایدار |
| بورس تهران | TSETMC (`cdn.tsetmc.com`) | قیمت با تأخیر؛ اگر نماد پیدا نشد با کد l18 هم می‌شود |
| شاخص کل | TSETMC | فقط شاخص |
| طلا و ارز | Navasan | کلید دمو `free`؛ برای پایداری از navasan.tech کلید رایگان بگیر و در آدرس جای‌گذاری کن |
| سهام آمریکا | Yahoo Finance | همراه نمودار مینیاتوری |
| اسکرپ وب | TGJU | نمونه‌ی HTML؛ سلکتورش را ممکن است نیاز به به‌روزرسانی داشته باشد |

## ۵. محدودیت‌ها (شفاف باشیم)

1. **بازه‌ی زمانی:** اندروید اجازه‌ی زیر ۵ ثانیه نمی‌دهد؛ عملاً ۱۰–۳۰ ثانیه نقطه‌ی شیرین است. برای «تیک‌به‌تیک» واقعی باید از WebSocket صرافی استفاده کنی (مثلاً `wss://stream.binance.com`) — این پروژه REST است، ولی ساختارش برای اضافه کردن WebSocket آماده است.
2. **دقت TSETMC:** دیتای سایت رسمی با تأخیر و گاهی کند است؛ صف‌های خرید/فروش را این پروژه نمی‌خواند (قابل اضافه شدن است).
3. **فیلترینگ:** اگر سایت مقصد در شبکه‌ی تو فیلتر است، ویجت هم نمی‌تواند بگیرد (مگر VPN گوشی روشن باشد). CoinGecko و Yahoo و TSETMC معمولاً بدون مشکل باز می‌شوند.
4. **باتری:** هر رفرش شبکه‌ی کوچکی است؛ با بازه‌ی ۱۵ ثانیه و ۳ نماد، مصرف محسوس نیست. تم شیشه‌ای روی نمایشگرهای OLED کم‌مصرف است چون بخشی از پس‌زمینه نیمه‌شفاف است.
5. این اپ برای استفاده‌ی شخصی خودت است؛ منتشر کردن عمومی‌اش در استور نیاز به رعایت قوانین و اجازه‌ی سایت‌های داده دارد.
